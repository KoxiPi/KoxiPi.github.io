# Shenglong Chen Portfolio

Static portfolio site prepared for GitHub Pages deployment.

## Included

- `index.html` single-page portfolio
- `styles.css` responsive visual system
- `script.js` lightweight reveal animation
- `assets/Shenglong_Chen_Resume.pdf` downloadable resume
- `assets/images/*` project screenshots

## Publish to GitHub Pages

1. Create or locate your GitHub Pages repository.
2. Copy these files into that repository root.
3. Push to the default branch or `gh-pages`, depending on your Pages setup.
4. Enable GitHub Pages in repository settings if it is not already enabled.

## Notes

- The site content is based on `Shenglong_Resume.pdf` and the project READMEs in the current workspace.
- Replace or add GitHub project links once your public repository URLs are confirmed.
